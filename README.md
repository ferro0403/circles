# Circle

Demo mobile-first di Circle: una web app per vedere cosa fanno gli amici e organizzare uscite nei gruppi.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Mock data locali, senza backend o autenticazione

## Avvio

```bash
npm install
npm run dev
```

Apri [http://localhost:3000](http://localhost:3000).

## Comandi

```bash
npm run dev
npm run build
npm run lint
```

## Struttura principale

- `app/`: pagine e route dell'App Router
- `components/`: componenti UI riutilizzabili
- `data/mock-data.ts`: tutti i dati mock della demo
